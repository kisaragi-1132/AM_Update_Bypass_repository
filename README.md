このリポジトリは、Minecraft java edition環境で、
Javaのインストール,Modローダーの取得および自動導入,MODパックの自動導入,ランチャーへの自動登録を行うことができるツールです。

現在は[クローズドバージョン]で、指定環境のみの動作に制限されていますが、最終的にはユーザーが設定を行えるようにする予定です。

現在の最新バージョンv1.6.0

[内部処理に Aria2c Qt Application Framework を使用しています]
